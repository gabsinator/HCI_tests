# HCI Tests

Practice material for the HCI lecture (SS26).

- `Ilias_Tests/` — the four Ilias tests as PDFs, plus personal notes on each
- `app/` — **HCI Exam Trainer**, an offline web app that replays those tests with
  Ilias-style partial-credit scoring and shows the solution for every question

## Quick start

Open `app/index.html` in a browser. No build step, no server, no dependencies.

See [app/README.md](app/README.md) for details on the questions, scoring and sources.
